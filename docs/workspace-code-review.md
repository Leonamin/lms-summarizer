- 종료 단계 옵션을 `processingOptions.ts`로 통합하고 파일 업로드는 다운로드 단계를 제외한다.
- 결과 다운로드 링크 중복 렌더링과 정렬·대상 페이지 계산 중복을 제거했다.
- 작업 결과 선택·단계·재개 계산을 `jobResults.ts`에 모아 화면별 판단 차이를 없앴다.
- 편집한 UI 상태·매개변수에는 `is`·`has`·`should` 접두사를 사용했다. 서버 JSON 필드 이름은 기존 API 계약을 유지한다.
- CSS는 원래 적용 순서를 보존했다. 분리 전후 빌드 CSS 파일은 모두 `index-D9wZhvs6.css`로 내용 해시가 같다.
