# 대시보드 개선 (작업 목록 · 자동 재생 · 레일)

## 작업 목록

- **페이지네이션**: 10/20개 단위 + `최신순/과거순` 정렬, 하단 `.job-pager`(범위·이동·개수 세그먼트).
  필터·검색·정렬·개수 변경 시 1페이지로 복귀. 데이터는 여전히 `allJobs()`가 전체를 가져온다(통계·SSE에 필요).
- **단계 표시**: `시작`(initial_stage) 열을 **4단계 미니 트랙**(`.stage-mini`, 상태 색)으로 교체 →
  어느 단계에서 대기/실패인지 드러난다. 행 맨 앞 대표 아이콘은 두지 않고, 선택 표시는 행 배경 + 현재 단계 슬롯 칩.
- 아이콘: `lucide-react`(shadcn 기본 셋, MIT·트리셰이킹) 도입. 다운로드 `ArrowDownToLine` / 오디오 변환
  `AudioLines` / 음성 인식 `Mic` / 요약 `Sparkles`. 상세 `StageTrack`도 같은 아이콘 사용.

## 자동 재생 (별도 큐)

- 자동 재생은 4단계 작업이 아니라 **별도 큐(`PlaybackQueue`, `playback.json`)** 임을 정리. 출석 확인 시
  자동 저장 **작업(Job)** 을 제출하고 그 작업이 4단계 파이프라인을 돈다.
- `AUTO PLAY` 그룹 확장: `지난 재생 N건` 토글로 완료/실패/중단 이력(출석·연결 작업·시각) 표시.
- 이력 필터 `전체/미출석/중단·실패`. 개요에 `미완료 재생` 카드(중단·실패 합계) → 클릭 시 필터 + 스크롤.
- 이력의 `작업 N` 클릭 → 작업 필터·검색 초기화 후 해당 페이지로 이동·선택·행 스크롤.

## 레일

- 접기/펼치기 토글을 **최상단**에 배치(펼침 264px / 접힘 78px). 좌우 패딩을 12px로 통일하고
  `.app-shell`의 `grid-template-columns`에 240ms 트랜지션을 넣어 본문이 부드럽게 이동. 상태는 `localStorage`.
